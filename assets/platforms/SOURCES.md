# Origens dos logótipos

Os símbolos desta pasta são marcas de terceiros. São mostrados para identificar
as plataformas; a MrStore não reivindica propriedade nem apoio comercial destas.

| Plataforma | Origem |
| --- | --- |
| UmbrelOS, CasaOS, Portainer | https://github.com/homarr-labs/dashboard-icons |
| ZimaOS, Dockge, Runtipi, Docker, HomeDock OS | https://github.com/selfhst/icons |
| Cosmos | https://github.com/azukaar/Cosmos-Server (`client/src/assets/images/icons/logo.svg`) |
| Olares | https://github.com/beclab/Olares (`apps/packages/app/config/Desktop/public/desktop/app-icon/os.svg`) |
| Homeio | https://github.com/doctor-io/homeio (`public/icon.png`, commit `13a40d496e57b8939f5efd2b54bd0ad0a702ca17`) |

Os logótipos SVG usam caminhos originais, sem desenhos substitutos. O PNG da
Homeio é carregado diretamente do ficheiro oficial fixado por commit no
GitHub; a Content Security Policy autoriza apenas essa origem adicional para
imagens. O conjunto selfh.st/icons disponibiliza arte sob CC BY 4.0.
Verificar as licenças e regras de marcas dos projetos de origem antes de
reutilizar estas imagens fora deste contexto.
